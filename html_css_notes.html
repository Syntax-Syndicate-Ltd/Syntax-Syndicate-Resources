HTML Notes

Introduction to HTML

HTML (HyperText Markup Language) is the standard markup language for creating web pages. It describes the structure of a web page using elements and tags.

Quick Tip

HTML stands for HyperText Markup Language. It's not a programming language but a markup language that tells browsers how to display content.

Key Concepts:
  • Elements: Building blocks of HTML pages
  • Tags: Labels used to mark up elements
  • Attributes: Provide additional information about elements
  • Nesting: Placing elements inside other elements

HTML Document Structure

Every HTML document follows a basic structure:

HTML 
<!DOCTYPE html>
<html>
<head>
    <title>Page Title</title>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <!-- Link to CSS files -->
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <!-- Page content goes here -->
    <h1>My First Heading</h1>
    <p>My first paragraph.</p>
</body>
</html>
Important Note

The <!DOCTYPE html> declaration defines the document type and HTML version. It must appear at the very beginning of the document.

HTML Elements and Tags

HTML elements are defined by a start tag, content, and an end tag:

HTML 
<tagname>Content goes here...</tagname>
Common HTML Elements:
  • Headings: <h1> to <h6>
  • Paragraphs: <p>
  • Links: <a>
  • Images: <img>
  • Lists: <ul>, <ol>, <li>
  • Divisions: <div>
  • Spans: <span>
Example
HTML 
<h1>This is a Heading 1</h1>
<h2>This is a Heading 2</h2>
<p>This is a paragraph.</p>
<a href="https://example.com">This is a link</a>
<img src="image.jpg" alt="Description">

HTML Attributes

Attributes provide additional information about HTML elements. They are always specified in the start tag and usually come in name/value pairs.

HTML 
<element attribute="value">Content</element>
Common Attributes:
  • id: Specifies a unique id for an element
  • class: Specifies one or more class names for an element
  • style: Specifies an inline CSS style for an element
  • title: Specifies extra information about an element
  • src: Specifies the source URL for an image
  • href: Specifies the URL for a link
  • alt: Specifies alternative text for an image
Example
HTML 
<a href="https://example.com" title="Visit Example">Link</a>
<img src="logo.png" alt="Company Logo" width="200">
<p class="highlight" id="intro">Introduction paragraph</p>

HTML Lists

HTML supports ordered, unordered, and description lists.

Unordered List (Bullet Points):
HTML 
<ul>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
</ul>
Ordered List (Numbered):
HTML 
<ol>
    <li>First item</li>
    <li>Second item</li>
    <li>Third item</li>
</ol>
Description List:
HTML 
<dl>
    <dt>Term 1</dt>
    <dd>Description for Term 1</dd>
    <dt>Term 2</dt>
    <dd>Description for Term 2</dd>
</dl>

HTML Tables

HTML tables are used to display data in rows and columns.

HTML 
<table>
    <thead>
        <tr>
            <th>Header 1</th>
            <th>Header 2</th>
            <th>Header 3</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Row 1, Cell 1</td>
            <td>Row 1, Cell 2</td>
            <td>Row 1, Cell 3</td>
        </tr>
        <tr>
            <td>Row 2, Cell 1</td>
            <td>Row 2, Cell 2</td>
            <td>Row 2, Cell 3</td>
        </tr>
    </tbody>
</table>
Quick Tip

Use <thead> for table headers, <tbody> for table body, and <tfoot> for table footer. This improves accessibility and structure.

HTML Forms

HTML forms are used to collect user input. They contain various input elements like text fields, checkboxes, radio buttons, submit buttons, etc.

HTML 
<form action="/submit-form" method="post">
    <div class="form-group">
        <label for="name">Name:</label>
        <input type="text" id="name" name="name">
    </div>
    
    <div class="form-group">
        <label for="email">Email:</label>
        <input type="email" id="email" name="email">
    </div>
    
    <div class="form-group">
        <label for="password">Password:</label>
        <input type="password" id="password" name="password">
    </div>
    
    <div class="form-group">
        <label>Gender:</label>
        <div>
            <input type="radio" id="male" name="gender" value="male">
            <label for="male">Male</label>
        </div>
        <div>
            <input type="radio" id="female" name="gender" value="female">
            <label for="female">Female</label>
        </div>
    </div>
    
    <div class="form-group">
        <label for="hobbies">Hobbies:</label>
        <select id="hobbies" name="hobbies" multiple>
            <option value="reading">Reading</option>
            <option value="sports">Sports</option>
            <option value="music">Music</option>
        </select>
    </div>
    
    <div class="form-group">
        <label>Interests:</label>
        <div>
            <input type="checkbox" id="coding" name="interests" value="coding">
            <label for="coding">Coding</label>
        </div>
        <div>
            <input type="checkbox" id="design" name="interests" value="design">
            <label for="design">Design</label>
        </div>
    </div>
    
    <div class="form-group">
        <label for="message">Message:</label>
        <textarea id="message" name="message" rows="4"></textarea>
    </div>
    
    <button type="submit">Submit</button>
</form>
Important Note

The action attribute specifies where to send the form data when the form is submitted. The method attribute specifies the HTTP method to use (GET or POST).

HTML5 Semantic Elements

HTML5 introduced semantic elements that clearly define different parts of a web page, making it more accessible and SEO-friendly.

Common Semantic Elements:
  • <header> - Represents introductory content
  • <nav> - Defines navigation links
  • <main> - Specifies the main content
  • <section> - Defines a section in a document
  • <article> - Defines independent content
  • <aside> - Defines content aside from main content
  • <footer> - Defines a footer for a section or page
  • <figure> - Specifies self-contained content
  • <figcaption> - Defines a caption for a figure
  • <time> - Defines a specific time
Example
HTML 
<!DOCTYPE html>
<html>
<head>
    <title>Semantic HTML Example</title>
</head>
<body>
    <header>
        <h1>Website Title</h1>
        <nav>
            <ul>
                <li><a href="#">Home</a></li>
                <li><a href="#">About</a></li>
                <li><a href="#">Contact</a></li>
            </ul>
        </nav>
    </header>
    
    <main>
        <section>
            <h2>Section Title</h2>
            <article>
                <h3>Article Title</h3>
                <p>Article content goes here...</p>
            </article>
        </section>
        
        <aside>
            <h3>Related Links</h3>
            <ul>
                <li><a href="#">Link 1</a></li>
                <li><a href="#">Link 2</a></li>
            </ul>
        </aside>
    </main>
    
    <footer>
        <p>© 2023 Website Name. All rights reserved.</p>
    </footer>
</body>
</html>

CSS Notes

Introduction to CSS

CSS (Cascading Style Sheets) is used to style and layout web pages. It controls the presentation of HTML elements, including colors, fonts, spacing, and positioning.

Quick Tip

CSS stands for Cascading Style Sheets. The "cascading" part means that styles can fall down from parent elements to child elements, creating inheritance.

Key Concepts:
  • Selectors: Patterns used to select elements to style
  • Properties: Style attributes that can be applied to elements
  • Values: Specific settings for properties
  • Cascading: How styles are applied based on specificity and inheritance

CSS Syntax

CSS consists of style rules that are interpreted by the browser and applied to the corresponding elements in your document.

CSS 
selector {
    property: value;
    property: value;
}
Example
CSS 
p {
    color: #333333;
    font-size: 16px;
    line-height: 1.5;
}

h1 {
    color: #2c3e50;
    font-size: 32px;
    margin-bottom: 20px;
}

CSS Selectors

Selectors are patterns used to select the elements you want to style. CSS has various types of selectors:

Common Selectors:
  • Element Selector: Selects elements based on the element name
  • Class Selector: Selects elements with a specific class attribute
  • ID Selector: Selects elements with a specific id attribute
  • Grouping Selector: Selects all elements with the same style definitions
  • Universal Selector: Selects all elements
CSS 
/* Element Selector */
p {
    color: blue;
}

/* Class Selector */
.highlight {
    background-color: yellow;
}

/* ID Selector */
#header {
    font-size: 24px;
}

/* Grouping Selector */
h1, h2, h3 {
    font-family: Arial, sans-serif;
}

/* Universal Selector */
* {
    box-sizing: border-box;
}
Advanced Selectors:
  • Descendant Selector: Selects elements that are descendants of a specified element
  • Child Selector: Selects elements that are direct children of a specified element
  • Adjacent Sibling Selector: Selects elements that are adjacent siblings of a specified element
  • General Sibling Selector: Selects elements that are siblings of a specified element
  • Attribute Selector: Selects elements based on attribute values
  • Pseudo-class Selector: Selects elements based on a certain state
  • Pseudo-element Selector: Selects and styles a part of an element
CSS 
/* Descendant Selector */
div p {
    color: green;
}

/* Child Selector */
ul > li {
    list-style-type: square;
}

/* Adjacent Sibling Selector */
h1 + p {
    font-weight: bold;
}

/* General Sibling Selector */
h1 ~ p {
    margin-top: 10px;
}

/* Attribute Selector */
input[type="text"] {
    border: 1px solid #ccc;
}

/* Pseudo-class Selector */
a:hover {
    color: red;
}

/* Pseudo-element Selector */
p::first-line {
    font-weight: bold;
}

CSS Box Model

The CSS box model is essentially a box that wraps around every HTML element. It consists of: content, padding, border, and margin.

CSS 
div {
    width: 300px;
    padding: 20px;
    border: 5px solid gray;
    margin: 10px;
}
Box Model Components:
  • Content: The actual content of the box (text, images, etc.)
  • Padding: Clears an area around the content (transparent)
  • Border: A border that goes around the padding and content
  • Margin: Clears an area outside the border (transparent)
Quick Tip

Use box-sizing: border-box; to include padding and border in the element's total width and height. This makes layout calculations easier.

CSS 
* {
    box-sizing: border-box;
}

CSS Layout

CSS provides various methods to control the layout of web pages:

Display Property:
CSS 
div {
    display: block; /* Default for div */
}

span {
    display: inline; /* Default for span */
}

li {
    display: inline-block; /* Combines block and inline */
}

.hidden {
    display: none; /* Hides the element */
}
Position Property:
CSS 
.static {
    position: static; /* Default position */
}

.relative {
    position: relative;
    top: 10px;
    left: 20px;
}

.absolute {
    position: absolute;
    top: 50px;
    left: 100px;
}

.fixed {
    position: fixed;
    bottom: 0;
    right: 0;
}

.sticky {
    position: sticky;
    top: 0;
}
Float Property:
CSS 
.float-left {
    float: left;
    width: 50%;
}

.float-right {
    float: right;
    width: 50%;
}

.clearfix::after {
    content: "";
    display: table;
    clear: both;
}
Flexbox Layout:
CSS 
.container {
    display: flex;
    flex-direction: row; /* row | row-reverse | column | column-reverse */
    justify-content: space-between; /* flex-start | flex-end | center | space-between | space-around */
    align-items: center; /* flex-start | flex-end | center | baseline | stretch */
    flex-wrap: wrap; /* nowrap | wrap | wrap-reverse */
}

.item {
    flex: 1; /* shorthand for flex-grow, flex-shrink, flex-basis */
    align-self: flex-start; /* auto | flex-start | flex-end | center | baseline | stretch */
}
Grid Layout:
CSS 
.grid-container {
    display: grid;
    grid-template-columns: 1fr 2fr 1fr; /* Define columns */
    grid-template-rows: auto 200px; /* Define rows */
    gap: 20px; /* Gap between grid items */
}

.grid-item {
    grid-column: 1 / 3; /* Column start and end */
    grid-row: 1 / 2; /* Row start and end */
}

CSS Responsive Design

Responsive web design makes web pages render well on a variety of devices and window or screen sizes.

Media Queries:
CSS 
/* For screens smaller than 768px */
@media (max-width: 768px) {
    body {
        font-size: 14px;
    }
    
    .container {
        width: 100%;
        padding: 0 15px;
    }
    
    .nav-menu {
        display: none;
    }
}

/* For screens between 769px and 1024px */
@media (min-width: 769px) and (max-width: 1024px) {
    .sidebar {
        width: 30%;
    }
    
    .main-content {
        width: 70%;
    }
}

/* For screens larger than 1024px */
@media (min-width: 1025px) {
    .container {
        max-width: 1200px;
        margin: 0 auto;
    }
}
Responsive Units:
CSS 
.container {
    width: 100%; /* Percentage of parent element */
    max-width: 1200px;
}

.text {
    font-size: 16px; /* Fixed size */
}

.responsive-text {
    font-size: 1rem; /* Relative to root font size */
}

.padding {
    padding: 2vw; /* Relative to viewport width */
}

.margin {
    margin: 5vh; /* Relative to viewport height */
}
Quick Tip

Use a mobile-first approach when designing responsive websites. Start with styles for small screens and then use media queries to enhance the design for larger screens.

CSS Animations and Transitions

CSS allows you to create animations and transitions to enhance user experience.

Transitions:
CSS 
.button {
    background-color: #4361ee;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 4px;
    transition: background-color 0.3s ease, transform 0.2s ease;
}

.button:hover {
    background-color: #3f37c9;
    transform: translateY(-2px);
}
Animations:
CSS 
@keyframes fadeIn {
    from {
        opacity: 0;
    }
    to {
        opacity: 1;
    }
}

@keyframes slideIn {
    0% {
        transform: translateX(-100%);
    }
    100% {
        transform: translateX(0);
    }
}

.fade-in {
    animation: fadeIn 1s ease-in-out;
}

.slide-in {
    animation: slideIn 0.5s ease-out;
}
Transforms:
CSS 
.rotate {
    transform: rotate(45deg);
}

.scale {
    transform: scale(1.5);
}

.translate {
    transform: translate(50px, 20px);
}

.skew {
    transform: skew(10deg, 5deg);
}

.multiple-transforms {
    transform: rotate(30deg) scale(1.2) translate(10px, 10px);
}
