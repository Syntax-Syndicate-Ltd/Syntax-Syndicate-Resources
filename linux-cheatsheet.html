File & Directory Management

ls

What it does

List directory contents. It is the primary way to see what files and folders exist in the current or a specified directory.

When to use it

Constantly. Use it to verify file creation, check permissions, or navigate the filesystem.

Basic Syntax

ls [options] [directory]

Important Options

  • -l : Long listing format (shows permissions, owner, size, date).
  • -a : All (includes hidden files starting with a dot).
  • -h : Human-readable sizes (e.g., 1K, 234M, 2G).
  • -t : Sort by modification time.

Beginner Tip: Use ls -lah as your go-to command for a detailed view of all files, including hidden ones.

cd

What it does

Change the current working directory.

When to use it

When you need to navigate to a specific folder to perform operations on files inside it.

Basic Syntax

cd [directory]

Important Options

  • cd ~ : Navigate to the home directory.
  • cd .. : Navigate up one level (parent directory).
  • cd - : Go back to the previous directory.

Beginner Tip: Typing just cd and hitting Enter always takes you back to your home folder, no matter where you are.

pwd

What it does

Print Working Directory. It displays the full path of the directory you are currently in.

When to use it

When you get lost in deep directory structures or need to copy the path for a script.

Basic Syntax

pwd
mkdir

What it does

Make Directory. Creates new folders.

When to use it

Organizing files or setting up project structures.

Basic Syntax

mkdir [options] directory_name

Important Options

  • -p : Parents (creates nested directories in one go, e.g., mkdir -p a/b/c).
  • -v : Verbose (prints a message for each created directory).

Beginner Tip: Always use -p in scripts to avoid errors if the directory already exists.

cp

What it does

Copy files or directories.

When to use it

Backing up configuration files before editing or duplicating data.

Basic Syntax

cp [options] source destination

Important Options

  • -r : Recursive (required to copy directories).
  • -i : Interactive (prompts before overwriting).
  • -v : Verbose (shows what is being copied).
  • -a : Archive mode (preserves permissions, times, and symbolic links).
mv

What it does

Move (rename) files or directories.

When to use it

Moving files into folders or renaming them to correct typos.

Basic Syntax

mv [options] source destination

Important Options

  • -i : Interactive (prompts before overwriting).
  • -v : Verbose.
  • -n : No clobber (do not overwrite an existing file).
rm

What it does

Remove files or directories.

When to use it

Cleaning up temporary files, cache, or unwanted data.

Basic Syntax

rm [options] file

Important Options

  • -r or -R : Recursive (removes directories and their contents).
  • -f : Force (ignores nonexistent files and prompts).
  • -i : Interactive (prompts for every removal).

Warning: rm -rf / will wipe your entire operating system. Deleted files are generally not recoverable from the command line.

touch

What it does

Update the access/modification timestamp of a file. If the file does not exist, it creates an empty one.

When to use it

Quickly creating a dummy file for testing or forcing a build system to recognize a change.

Basic Syntax

touch [options] filename

File Viewing & Reading

cat

What it does

Concatenate and print files to the screen.

When to use it

Reading short files, combining multiple files, or quickly checking script content.

Basic Syntax

cat [options] file

Important Options

  • -n : Number all output lines.
  • -b : Number non-empty output lines.
  • -s : Squeeze blank lines (suppresses repeated empty lines).
less

What it does

View file contents one page at a time (with scrolling/searching).

When to use it

Reading large log files or long configuration files. It is preferred over more.

Basic Syntax

  • b : Backward one page.
  • /pattern : Search for text.
  • q : Quit.

Beginner Tip: You can pipe output to less (e.g., ls -lah | less) to browse through long directory listings.

head

What it does

When to use it

Checking the header of a CSV file or the first few lines of a log to see recent events.

Basic Syntax

head [options] file

Important Options

  • -n 20 : Show the first 20 lines (default is 10).
tail

What it does

Output the last part of files.

When to use it

Monitoring active log files (like /var/log/syslog) in real-time.

Basic Syntax

tail [options] file

Important Options

  • -n 50 : Show the last 50 lines.
  • -f : Follow (output appended data as the file grows).

Beginner Tip: tail -f is your best friend for debugging application crashes or server issues live.

nano

A simple, beginner-friendly text editor.

When to use it

Making quick edits to config files when you don't know Vim.

Basic Syntax

nano filename

Important Options

  • Ctrl + O : Save (WriteOut).
  • Ctrl + X : Exit.
vim

What it does

A highly configurable, modal text editor.

When to use it

Editing files over slow SSH connections, writing scripts, or system administration tasks where efficiency is key.

Basic Syntax

vim filename

Modes & Commands

  • i : Insert mode (start typing).
  • Esc : Normal mode (stop typing).
  • :w : Save.
  • :q : Quit.

Gotcha: If you get stuck in Vim, press Esc, then type :q! and hit Enter to force exit.

Permissions & Ownership

chmod

What it does

Change file mode bits (permissions).

When to use it

Making a script executable (+x) or restricting access to sensitive files.

Basic Syntax

chmod [options] mode file

Important Options

  • u+x : Add execute permission for user (owner).
  • g-r : Remove read permission for group.
  • 755 : Numeric mode. Owner: rwx, Group: r-x, Others: r-x.
  • -R : Recursive (apply to all files in a directory).

Beginner Tip: chmod +x script.sh is the most common usage to make a script run.

chown

What it does

Change file owner and group.

When to use it

When you transfer files between users or need a web server (like www-data) to own a specific directory.

Basic Syntax

chown [options] user:group file

Important Options

  • user:group : Set both user and group.
  • :group : Change only the group.
  • -R : Recursive.

Warning: You cannot give away files to other users (e.g., a regular user cannot chown a file to 'root'). Only root can do that.

chgrp

What it does

Change group ownership.

When to use it

Adding a file to a specific team group for collaboration.

Basic Syntax

chgrp [options] group file

Important Options

  • -R : Recursive.
  • -v : Verbose.
umask

What it does

Sets the default permission mask for creating new files and directories.

When to use it

Ensuring secure defaults in a shell environment (e.g., forcing new files to be readable only by the owner).

Basic Syntax

umask [mode]

Common Values

  • 022 : Default. New files are 644 (rw-r--r--), dirs are 755.
  • 077 : Private. New files are 600 (rw-------), dirs are 700.

Search & File Discovery

find

What it does

Search for files in a directory hierarchy.

When to use it

Locating specific files by name, size, type, or modification time anywhere on the disk.

Basic Syntax

find [path] [options]

Common Examples

  • find . -name "filename.txt" : Search current dir.
  • find / -type d -name "logs" : Find directories named logs.
  • find . -size +100M : Find files larger than 100MB.
grep

What it does

Print lines matching a pattern. It searches text, not filenames.

When to use it

Finding a specific configuration setting in a file or searching for an error code in logs.

Basic Syntax

grep [options] "pattern" file

Important Options

  • -i : Case insensitive.
  • -r : Recursive (search all files in a directory).
  • -v : Invert match (show lines that do NOT match).
  • -n : Show line numbers.
  • -E : Extended regex (useful for complex patterns).
locate

What it does

Find files by name quickly using a pre-built database.

When to use it

When you need to find a file instantly and don't care if it was created 1 minute ago.

Basic Syntax

locate [options] filename

Gotchas

You must run updatedb (as root) periodically to refresh the database. It will not find newly created files until the database updates.

which

What it does

Locate a command (shows the full path of the executable).

When to use it

Checking which version of a binary is actually running (e.g., checking if Python is in /usr/bin or /usr/local/bin).

Basic Syntax

which command_name
whereis

What it does

Locate the binary, source, and manual page files for a command.

When to use it

More thorough than which; useful when finding documentation or header files.

Basic Syntax

whereis command_name

Text Processing

sed

What it does

Stream Editor. Used for filtering and transforming text.

When to use it

Replacing a specific string in a file or deleting lines matching a pattern automatically.

Basic Syntax

sed [options] 'command' file

Common Examples

  • sed 's/old/new/g' file.txt : Replace all occurrences of "old" with "new".
  • sed '5d' file.txt : Delete the 5th line.
  • -i : Edit file in-place (save changes to the file).
awk

What it does

A powerful programming language for pattern scanning and processing.

When to use it

Extracting specific columns from a text file (like CSV) or log output based on delimiters.

Basic Syntax

awk 'program' file

Common Examples

  • awk '{print $1}' file.txt : Print the first column.
  • awk -F: '{print $1}' /etc/passwd : Print the first field using colon as separator.
sort

What it does

Sort lines of text files.

When to use it

Organizing log files, lists of names, or analyzing data.

Basic Syntax

sort [options] file

Important Options

  • -n : Numeric sort (2 comes before 10).
  • -r : Reverse order.
  • -u : Unique lines (remove duplicates).
  • -k : Sort by a specific column.
uniq

What it does

Report or omit repeated lines.

When to use it

Finding unique occurrences in a log (e.g., counting unique IP addresses). Note: input must be sorted first.

Basic Syntax

uniq [options]

Important Options

  • -c : Prefix lines by the number of occurrences.
  • -d : Only print duplicate lines.
diff

What it does

Compare files line by line.

When to use it

Seeing what changed between a backup file and the current version, or comparing code versions.

Basic Syntax

diff [options] file1 file2

Important Options

  • -u : Unified format (easier to read).
  • -q : Brief (only report if files differ).
  • -r : Recursive (compare directories).
wc

What it does

Word, line, character, and byte count.

When to use it

Quickly counting lines in a file (e.g., how many entries in a log).

Basic Syntax

wc [options] file

Important Options

  • -l : Lines.
  • -w : Words.
  • -c : Bytes.

Compression & Archiving

tar

What it does

Tape ARchive. Groups multiple files into one archive (often called a tarball).

When to use it

Creating backups or distributing software source code.

Basic Syntax

tar [options] archive_name files

Important Options

  • -c : Create archive.
  • -x : Extract archive.
  • -v : Verbose.
  • -f : File (specify filename of the archive).
  • -z : Gzip compression (.tar.gz).
  • -j : Bzip2 compression (.tar.bz2).

Common Usage: tar -czvf archive.tar.gz /path/to/dir

gzip

What it does

Compress or expand files.

When to use it

Reducing the size of a single file to save disk space or bandwidth.

Basic Syntax

gzip [options] file

Important Options

  • -d : Decompress.
  • -k : Keep original file (don't delete it after compressing).
  • -9 : Best compression (slowest).
zip

What it does

Package and compress (archive) files. More common in Windows environments but supported on Linux.

When to use it

When you need to send files to Windows users.

Basic Syntax

zip [options] archive.zip file1 file2

Important Options

  • -r : Recursive (include directories).
unzip

What it does

Extract files from a ZIP archive.

When to use it

Opening archives downloaded from the internet or received from Windows users.

Basic Syntax

unzip [options] archive.zip

Important Options

  • -l : List files without extracting.
  • -d : Specify destination directory.

Basic Syntax

df [options]

Important Options

  • -h : Human-readable (GB, MB).
  • -T : Print filesystem type.

du

What it does

Estimate file space usage.

When to use it

Finding which specific directories are consuming the most space.

Basic Syntax

du [options] directory

Important Options

  • -s : Summarize (total only).
  • --max-depth=1 : Check only top-level directories.
mount

What it does

Mount a filesystem.

When to use it

Attaching a USB drive, a new hard disk, or a network share (NFS/SMB) to the directory tree.

Basic Syntax

mount [options] device directory

Common Usage

umount

What it does

Unmount file systems.

When to use it

Safely removing a drive before physically unplugging it.

Basic Syntax

umount [options] directory

fdisk

What it does

Manipulate disk partition table.

When to use it

Creating new partitions on a fresh hard drive or modifying existing ones.

Basic Syntax

fdisk [options] device

Common Usage

  • fdisk -l : List all partitions.

Warning: Modifying partitions destroys data. Use with extreme caution.

lsblk

What it does

List block devices.

When to use it

Visualizing the hierarchy of storage devices and their partitions in a tree structure.

Basic Syntax

lsblk [options]

Important Options

  • -f : Show filesystems.
  • -m : Show permissions/owner.
mkfs

What it does

Build a Linux filesystem.

When to use it

Formatting a partition (e.g., to ext4) after creating it with fdisk.

Basic Syntax

mkfs -t [type] device

Common Usage

Process Management

ps

What it does

Report a snapshot of current processes.

When to use it

Checking the Process ID (PID) of a running application to kill or debug it.

Basic Syntax

ps [options]

Important Options

  • aux : View all processes for all users (BSD syntax).
  • -ef : View all processes full format (System V syntax).
  • -u username : Filter by specific user.
top

What it does

Display Linux processes. A dynamic, real-time view.

When to use it

Monitoring server load, CPU usage, and RAM usage in real-time.

Basic Syntax

top

Controls

  • q : Quit.
  • Shift + M : Sort by memory usage.
  • Shift + P : Sort by CPU usage.
  • k : Kill a process (requires PID).
htop

What it does

Interactive process viewer. A more colorful, user-friendly version of top.

When to use it

Preferred over top for easier interaction (mouse support in some versions, clearer layouts).

Basic Syntax

htop

Controls

  • F10 : Quit.
  • F9 : Kill process.
  • u : Show processes of a single user.
kill

What it does

Terminate a process.

When to use it

Stopping a frozen or misbehaving program.

Basic Syntax

kill [signal] PID

Important Signals

  • -15 or -TERM : Terminate politely (asks app to close).
  • -9 or -KILL : Force kill immediately.

Warning: Use -9 only as a last resort. It does not allow the program to save data or clean up temporary files.

killall

What it does

Kill processes by name.

When to use it

Stopping all instances of a program (e.g., killing all Chrome tabs/processes at once).

Basic Syntax

killall [options] process_name

Important Options

  • -9 : Force kill.
  • -i : Interactive (ask before killing).
pkill

What it does

Signal processes based on name and other attributes. More direct than killall.

When to use it

Killing a process that matches a specific pattern (e.g., pkill -f "python script.py").

Basic Syntax

pkill [options] pattern
nohup

What it does

Run a command immune to hangups (logout).

When to use it

Starting a long-running script or server that must stay alive even after you close the SSH session.

Basic Syntax

nohup command &

history

Beginner Tip: Type !100 (where 100 is the line number) to re-run that specific command. Press Ctrl + R to search history interactively.

alias

What it does

Create an alias (a shortcut for a command).

When to use it

Shortening long commands or adding default flags (e.g., always making rm interactive).

Basic Syntax

alias name='command'

Example

  • alias ll='ls -lah'
source

What it does

Execute commands from a file in the current shell.

When to use it

Applying changes to your shell configuration file (like .bashrc) without restarting the terminal.

Basic Syntax

source filename

Input / Output Redirection & Pipes

> (Standard Output Redirection)

What it does

Redirects output to a file, overwriting the file if it exists.

When to use it

Saving the result of a command to a file.

Example

ls -la > filelist.txt
>> (Append Redirection)

What it does

Redirects output to a file, appending to the end of the file.

When to use it

Adding logs to an existing file.

Example

echo "New entry" >> logfile.txt
< (Input Redirection)

What it does

Passes the content of a file as input to a command.

When to use it

Reading commands from a file or processing file content line by line.

Example

sort < names.txt
| (Pipe)

What it does

Connects the output of one command to the input of another.

When to use it

Chaining commands together to perform complex operations (e.g., filtering output).

Example

cat error.log | grep "404"
xargs

What it does

Build and execute command lines from standard input.

When to use it

Passing a list of files (output from find) to another command (like rm or chmod).

Example

find . -name "*.tmp" | xargs rm
tee

What it does

Reads from standard input and writes to standard output and files.

When to use it

Viewing output on the screen while simultaneously saving it to a file.

Example

ls -la | tee filelist.txt

System Control & Power

systemctl

What it does

Control the systemd system and service manager.

When to use it

Starting, stopping, restarting services (e.g., nginx, docker, ssh).

Basic Syntax

systemctl [command] [service]

Common Commands

  • systemctl start service
  • systemctl stop service
  • systemctl restart service
  • systemctl enable service : Start on boot.
  • systemctl status service
shutdown

What it does

Schedule a time for the system to be powered down.

When to use it

Safely shutting down a server.

Basic Syntax

shutdown [options] [time]

Important Options

  • -h : Halt (power off).
  • -r : Reboot.
  • -c : Cancel a pending shutdown.
  • now : Do it immediately.
reboot

What it does

Restart the system.

When to use it

Applying kernel updates or flushing system state.

Basic Syntax

sudo reboot
poweroff

What it does

Power off the machine.

Basic Syntax

sudo poweroff

Job Scheduling & Automation

crontab

What it does

Maintain crontab files for individual users.

When to use it

Scheduling scripts to run automatically at specific times (e.g., a daily backup at 2 AM).

Basic Syntax

crontab [options]

Important Options

  • -e : Edit the user's crontab.
  • -l : List the user's crontab.
  • -r : Remove the user's crontab.

Syntax: * * * * * command (Minute, Hour, Day of Month, Month, Day of Week).

at

What it does

Queue, examine, or delete jobs for later execution.

When to use it

Scheduling a one-time job to run in the future.

Basic Syntax

at [time]

Example

echo "backup.sh" | at 5pm

Logs & Monitoring

journalctl

What it does

Query the systemd journal.

When to use it

Viewing boot logs, service logs, and kernel messages on systemd-based distros.

Basic Syntax

journalctl [options]

Important Options

  • -u service_name : Filter by specific service.
  • -f : Follow log output (real-time).
  • -b : Show logs from current boot.
  • -p err : Filter by priority (error, warning, etc).
